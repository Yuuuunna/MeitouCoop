# 物品与犯罪

[总索引与证据口径](behaviour-map.md)。默认 **Observed**。

## 物品与买卖

依据：[物品窗口](ui-screens.md#6-inventory-trade-dialogue-build)、[经济](economy.md)、[物品所属](carry-loot.md#stolen-ownership)、[图纸](buildings-production.md#blueprints)。

| ID | 操作与前提 | 状态与反馈 | 下一步或失败分支 |
|---|---|---|---|
| P01 | 打开自身、背包或目标库存 | 展示物品格、装备槽及数量 | 查看、转移、装备或关窗；开窗与完成转移分开 |
| P02 | 拖动物品到可容纳位置 | 成功放置、交换或合并；空间和类型不合则不能放 | 换位置、退回、移往别的容器 |
| P03 | 操作堆叠及修饰键 | 按该入口处理单件或整堆 | 数量守恒；不同容器的堆叠能力不能混同 |
| P04 | 两个可交互库存之间快捷转移 | 物品进入目标可用格/堆叠 | 满格、距离、权限、重量等限制应保留余物与反馈 |
| P05 | 拾取、丢弃或交给另一角色 | 物品在世界和角色/容器间转移 | 再拾取、运输、交易；物品归属不会因所有移动都自动清空 |
| P06 | 穿脱武器、护甲及合适装备 | 装备槽、外观与有效属性改变 | 进入战斗或继续换装；种族、部位与槽位限制仍适用 |
| P07 | 穿脱背包并放入物品 | 容量、堆叠、重量修正和装备惩罚变化 | 整包运输、卸包作战或分拣；包内物不能凭空丢失 |
| P08 | 放入/取出材料、成品或食物 | 机器、专用储物与角色库存发生转移 | 生产、自动搬运或取食；专用储物限制物品种类 |
| P09 | 读取地图物品 | 更新可见地点信息 | 在世界地图查看并前往；不等于已实际探索该地点 |
| P10 | 使用可学习图纸 | 解锁对应研究或制造知识 | 获得相应建造/配方入口；已经学会、前提与消耗规则见研究资料 |
| P11 | 取得可兑换货币物品 | 按物品规则计入阵营资金 | 买卖、招募、交费；不把所有贵重物品自动变钱 |
| P12 | 商人对话开启贸易 | 展示商品、价格、双方资金和玩家物品 | 买卖，或因距离/商人状态结束；不是任意 NPC 都有商店 |
| P13 | 购买商品，有资金及空间 | 扣款，商品进入买方库存 | 装备、消费、转卖；不能超额扣款或复制商品 |
| P14 | 出售商品，商人接受且有资金 | 商品离开库存，资金增加 | 继续交易；赃物和违禁品另走 P21/P22 |
| P15 | 单件、整堆交易及本次交易回购 | 交易数量、余额和可回购内容变化 | 不足时按该入口处理可成交量；关窗后的回购边界待复核 |
| P16 | 跨商店、区域交易或等待刷新 | 商品供给、资金和价格条件可能不同 | 跑商或等待；不是物理模拟每件商品的全球物流 |
| P17 | 玩家销售柜放入允许的商品 | 符合条件的 NPC 可购买，产生收入及库存变化 | 补货、调公共访问；购买者预算和购物需求限制结果，见 B31 |

## 犯罪、拘押与逃脱

依据：[目击与偷窃](carry-loot.md#theft-and-witnesses)、[销赃](economy.md#fencing-stealing-and-smuggling)、[法律](economy.md#crimes-bounties-and-prisoners)、[锁](locks.md)、[奴隶 AI](ai.md#prisoner-and-slaver-packages)。

| ID | 操作与前提 | 状态与反馈 | 下一步或失败分支 |
|---|---|---|---|
| P18 | 进入他人禁入区域或逗留私人房屋 | 可能受到警告、驱逐或犯罪响应 | 离开、隐藏、拒绝；公共状态与时间/所属需分别核对 |
| P19 | 对锁使用撬锁、工具、力量或砸门 | 持续尝试、进度/成功率、工具与门锁状态变化 | 成功可通行或开库存；太难、缺工具、目击、战斗可阻断 |
| P20 | 从他人物品、容器或角色取物 | 转移物品并按情境进行盗窃、扒窃及目击判断 | 成功也可能保留赃物归属；失败引出警报、追击 |
| P21 | 把赃物卖给商人 | 按商人与物品所属处理接受、识破或销赃 | 得钱或触发犯罪响应；不是换一次包就保证洗白 |
| P22 | 携带或出售当地违禁品、遇检查 | 查验、对话、走私交易或处罚分支 | 配合、贿赂、逃跑等取决于实际对话内容 |
| P23 | 无端攻击、绑架等被认定犯罪 | 对应派系的警戒、犯罪记录、赏金或关系发生变化 | 逃离、抵抗、投案或拘捕；不是全世界统一执法 |
| P24 | 守卫/赏金猎人发现可拘捕人物 | 接近、交战、制服、搬运并关押 | 服刑、保释、营救或逃脱；搜缴/治疗取决于 NPC 行为 |
| P25 | 捕获悬赏目标并交给接受它的势力 | 通过对话或相应笼子交付，符合条件时领奖 | 资金与已领取状态变化；活体/遗体收益不同且不可重复领取 |
| P26 | 角色被关押并有相应刑期/对话 | 等待释放，或在可用对话中支付保释等费用 | 释放后离开；并非所有牢笼都有自动到期释放 |
| P27 | 奴隶贩子俘获、购买或接收人物 | 奴隶身份、装备/镣铐、工作和拘束行为发生变化 | 服从、救援或逃脱；被俘没有必然终止游戏 |
| P28 | 解镣铐、开笼、离开奴役控制区 | 由被拘束转向逃脱及逃奴相关状态 | 躲藏、换装、等待、继续远离；身份识别与实体锁分开 |
| P29 | 逃脱或犯罪后再遇守卫、主人、猎人 | 根据关系、记忆、赏金与逃奴状态识别并响应 | 被追捕、再次俘虏或安全通过；脱战不等于记录已清除 |
| P30 | 解救、赎买或放走其他囚犯/奴隶 | 对方按性格、条件与对话内容作出反应 | 跟随、逃跑、加入或拒绝；释放不保证成为玩家成员 |

**Unknown**：每类犯罪的目击/记忆期限、并发转移时的拒绝反馈、囚犯搜缴与归还物品的全部条件、所有奴隶身份转移及招募分支。
“可关押人物”不推出“可任意控制囚犯劳动或招募所有囚犯”；此类能力需要原版内容入口证据。
