# 会话与控制

[总索引与证据口径](behaviour-map.md)。下表默认 **Observed**；本节不定义新的默认快捷键。

## 会话

依据：[界面与新游戏](ui-screens.md#title-screen-and-its-windows)、[存档与导入](../formats/save.md)、[设置](../formats/settings.md)。

| ID | 入口与条件 | 操作后发生什么 | 下一步与限制 |
|---|---|---|---|
| C01 | 标题页，有可继续的存档 | Continue 载入最近游戏 | 回到世界；不可读存档的反馈待核对 |
| C02 | New game 选择开局 | 显示开局说明，确定初始人手、资金、地点及关系等 | 选择高级选项或开始；不是所有开局都同条件 |
| C03 | 新游戏高级选项 | 调整饥饿、伤害、人口等世界参数 | 开始游戏；数值范围见设置文档 |
| C04 | 角色编辑 | 在该开局允许的种族、性别和外观范围内编辑、命名、随机化或导入外观 | 确认进入世界；各开局可编辑项需分别核对 |
| C05 | 游戏中保存 | 将当前世界及玩家状态写入命名存档；覆盖涉及确认 | 继续游戏、载入或退出 |
| C06 | 快速保存、定时自动保存 | 写入相应槽位 | 从该槽继续；间隔与轮换由设置决定 |
| C07 | 载入选定存档 | 恢复保存的世界、人物与进度 | 继续行为链；位置重置是独立选项 |
| C08 | Load 的 Reset squad positions | 载入时重置玩家队伍位置 | 用于恢复卡住队伍；不等于导入世界 |
| C09 | Import 选定存档及保留项 | 重建世界，按选项继承玩家队伍、建筑、研究、重要 NPC 状态、关系等 | 继续游戏；不等于普通读档，完整保留规则见存档文档 |
| C10 | 存档列表选中条目并删除 | 弹确认；当前使用中的存档受限制 | 确认后移除；取消保留 |
| C11 | Esc 菜单、返回标题或退出 | 打开会话操作或退出确认 | 取消、保存、载入或结束；未保存进度不应假定已落盘 |
| C12 | 设置、帮助和制作人员入口 | 编辑设置、查看教程或字幕名单 | 返回；教程重置、重启生效项见设置文档 |

## 操作队伍与观察世界

依据：[输入](ui-input.md#dispatch-and-selection)、[地图](ui-screens.md#map)、[小队](ui-screens.md#squads-tab)、[时间](game-loop.md#speed-and-pause)、[移动](pathfinding.md)。

| ID | 入口与条件 | 操作后发生什么 | 下一步与限制 |
|---|---|---|---|
| C13 | 左键自有单位或头像 | 选择可指挥成员，HUD 改为相应人物 | 下命令、查看状态；检查他人不赋予控制权 |
| C14 | 框选、追加选择、选整个小队 | 改变命令接收者集合 | 同令多人；具体执行者可能是全选或其中一人，见 I01–I03 |
| C15 | 切小队、切成员、聚焦人物 | 更改当前小队、选择或镜头焦点 | 指挥异地队伍；三者不是同一状态 |
| C16 | 镜头平移、旋转、缩放、跟随 | 改变观察位置 | 可选目标与可见楼层随视角变化 |
| C17 | 切楼层、室内显示 | 显示对应楼层及室内对象 | 选择室内目标、楼梯或屋顶通路；遮挡影响点选 |
| C18 | 高亮物品、招牌、目标 | 显示标签、提示或轮廓 | 检查所属、状态并交互；遮挡和高亮不是拾取许可 |
| C19 | 打开地图，缩放、拖动、查看标记 | 显示已发现地点、队伍和行程信息 | 在地图下移动令；发现与实际探索是不同状态 |
| C20 | 右键地面或地图目的地 | 单位寻路移动；世界有目的地反馈 | 到达、遭遇、被门挡住或改令；不是传送 |
| C21 | 调整步行、奔跑、组队速度及跟随队形 | 改变行进方式 | 负重、伤腿、地形和队伍成员限制实际速度 |
| C22 | 停止或另下命令 | 当前动作被停止或替换 | 常驻工作和自动行为可能重新接管，见 B06 |
| C23 | 暂停、恢复、切时间速度 | 改变世界推进速度 | 暂停时仍可观察和准备命令；UI 动画与游戏时间分开 |
| C24 | 创建、命名小队，移动成员 | 重组可指挥成员 | 切换小队与分工；不是招募新角色 |
| C25 | 解雇成员 | 确认后失去该成员控制权 | 成员进入 NPC 行为；最后一名成员有保护限制 |
| C26 | 人物、物品、建筑信息与悬浮提示 | 显示属性、伤势、物品效果、工作和原因 | 据此选择医疗、换装、补料或其他操作 |
| C27 | 消息、伤害数字、对话记录、警报 | 世界事件变成可见反馈 | 查看来源并响应；不把每种通知另算成玩法 |
| C28 | 隐藏 HUD、截图、输入框及快捷键 | 改变界面或输入焦点 | 输入文字时不能误触世界命令；恢复 HUD 继续 |

## 启动与兼容边界

依据：[安装与模组装载](../formats/overview.md)、[设置](../formats/settings.md)、[本地化](../formats/localisation.md)、[资源格式](../formats/overview.md)、[音频](../audio.md)。

| ID | 入口与条件 | 操作后发生什么 | 下一步与限制 |
|---|---|---|---|
| C29 | 启动配置与模组列表 | 选择模组并确定顺序，装载基础内容与覆盖项 | 新游戏或读档；依赖、覆盖冲突与缺失资源是独立兼容问题 |
| C30 | 语言选择 | 使用对应文本、字体及内容翻译 | UI、名称、提示、对话均需显示；不是只翻译主菜单 |
| C31 | 视频设置、窗口与分辨率 | 改变显示、画质、可见距离等 | 按设置应用或重启；不把 Meitou 特有画质功能计作原版 |
| C32 | 音量设置和游戏事件 | 控制音乐、环境、动作和界面音效 | 事件消失或场景切换时声音需相应结束或变化 |
| C33 | 镜头跨区域、切远方队伍 | 加载地形、建筑、角色、碰撞与导航等内容 | 可见场景与持久状态一致；等待加载也是玩家可见行为 |
| C34 | 原版或模组提供新内容 | 新物品、种族、建筑、对话、开局进入对应能力链 | 不能只支持硬编码的原版实例；具体格式见资源文档 |
| C35 | 游戏内世界编辑、导航修复快捷入口 | 提供编辑或修复工具 | 属于工具兼容范围；逐按钮行为 **Unknown**，不混入常规玩法完成率 |
| C36 | FCS 制作或修改内容 | 编辑器产物被游戏读取 | Meitou 的目标是读取兼容；是否替代编辑器不由游戏能力清单推出 |

**Unknown**：窗口失焦与模态窗口对暂停的全部影响、世界移动的 Shift 排队规则、取消命令后的恢复优先级、异常存档/模组的完整反馈。
地图移动不能据世界点击推断：已有[地图记录](ui-screens.md#map)明确其 Shift 不增加队列。
