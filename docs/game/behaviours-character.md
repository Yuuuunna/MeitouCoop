# 角色与生存

[总索引与证据口径](behaviour-map.md)。默认 **Observed**；角色自身变化也是能力链，即使没有专门按钮。

## 战斗与失去行动能力

依据：[战斗](combat.md)、[角色伤势](character-stats.md)、[倒地与装死](ragdolls.md)、[搬运](carry-loot.md)。

| ID | 操作或触发条件 | 状态与可见结果 | 后续可做什么及限制 |
|---|---|---|---|
| H01 | 攻击命令、被袭击或保护对象遭攻击 | 接近目标、选战斗位置并自动攻防 | 改目标、撤离、换行为开关；不是玩家逐刀手动连招 |
| H02 | 近战武器可用且进入攻击范围 | 使用武器动作，命中、格挡或未命中 | 伤害及经验变化；武器要求、距离、室内和伤势影响效果 |
| H03 | 无可用武器，允许徒手作战 | 使用武术及闪避行为 | 随技能与身体状态改变可用动作；不等同于持械格挡 |
| H04 | 受击，装备覆盖相应部位 | 护甲与部位规则改变伤害，产生动作、血迹/火花等反馈 | 伤势进入 H09–H12；不是只扣一条总血量 |
| H05 | 配备可用弩、弹药，启用远程行为 | 瞄准、发射、装填，弹药消耗 | 失去射界、弹药耗尽、近身等导致调整；有误伤风险 |
| H06 | 操作炮塔，具备对应使用条件 | 从炮位瞄准并射击 | 目标移动、遮挡、电力或操作者伤势改变结果；炮塔不套用弩箭库存规则 |
| H07 | 切 Block / Hold / Passive / Ranged / Taunt | 改变防御、移动、主动接敌、武器选择或吸引敌人的策略 | 开关组合有相互影响；Passive 不等于无敌或停止自卫 |
| H08 | 战斗中移动、停止或离开敌人 | 重定位、尝试退出战斗或继续遭追击 | 可再次接战、躲避、求援；逃离没有必然成功保证 |
| H09 | 各身体部位受伤、失血或饥饿 | 有效属性、行动、武器使用随身体状态变化 | 包扎、夹板、维修、减负、休息或进食 |
| H10 | 失血或关键部位伤势造成昏迷 | 暂失控制，可能继续恶化 | 等待恢复、被救援、被搜身/俘虏；倒地不等于死亡 |
| H11 | 苏醒但伤势或威胁仍在 | 可能恢复、保持低姿态、装死或爬行 | 起身、潜行离开、被搬运；各状态条件见倒地文档 |
| H12 | 致命伤、持续恶化等达到死亡条件 | 人物死亡，留下可处理遗体和装备 | 搜身、搬尸、处置；该人物不能靠普通治疗继续成长 |
| H13 | 背起人形或可搬运动物 | 搬运双方进入关联状态，携带者负担和活动受影响 | 放下、放床、关笼、交付；携带者倒地需正确解除关系 |

## 治疗、食物与长期成长

依据：[医疗与经验](character-stats.md)、[床](locks.md#beds)、[动物](animals.md)、[感知](perception.md)、[小队 AI](ai-tasks.md#squad-ai-options)。

| ID | 操作或触发条件 | 状态与可见结果 | 后续可做什么及限制 |
|---|---|---|---|
| H14 | 对伤员急救，有对应医疗用品 | 消耗用品，处理可治疗伤口、减少继续恶化 | 仍需时间恢复；工具耗尽、距离或打断可中止 |
| H15 | 对可夹板处理伤肢操作 | 夹板改善伤肢的临时可用程度 | 随恢复变化；不生长新肢体 |
| H16 | 休养或进入普通床/睡袋 | 随时间恢复，床提供相应恢复条件 | 起床、继续治疗、恢复工作；租用与占用是进入前提 |
| H17 | 机械身体或义肢受损、积累磨损 | 修理包与修理床处理不同层次的损伤 | 补工具、进入合适修理床；不能以普通急救替代全部维修 |
| H18 | 时间推进且种族需要食物 | 饥饿变化，严重时虚弱、昏倒及进一步恶化 | 获得适合种族的食物；不是“所有人物都同样需要吃饭” |
| H19 | 饥饿且有可用食物 | 自动取食并消耗营养；不是通用右键 Eat 命令 | 自身背包、允许的分享与补给来源影响能否吃到 |
| H20 | 修改 Share Food / Feed Animals 等 AI 选项 | 改变队内共享和动物进食的允许条件 | 距离、容器与食物种类仍约束供应；见 B05/B27 |
| H21 | 执行跑步、负重、战斗、治疗、生产等活动 | 对应技能/属性积累经验，能力改变 | 可看属性与装备修正；不假定每次动作都奖励相同经验 |
| H22 | 开潜行并接近其他角色 | 潜行状态、被观察反馈及发现风险变化 | 躲藏、偷袭、偷物、逃离；光照、距离、技能和装备影响暴露 |
| H23 | 穿着其他派系制服等伪装 | 可改变他人识别与警戒反应 | 混入或被识破；制服不是自动更换真实派系 |
| H24 | 肢体丢失或失去功能 | 可见缺肢，移动与持械能力受限 | 救援、装合适义肢、换装备；肢体规则受种族及设置约束 |
| H25 | 缺肢槽安装、卸下或更换义肢 | 改变身体能力、装备效果和维护需求 | 维修与替换；不能当作原生肢体的普通护甲槽 |
| H26 | 种族及装备组合变化 | 食物、生命部位、装备槽、环境抗性和技能修正不同 | 同一操作需按种族检查，尤其动物与机械种族 |
| H27 | 购买或通过内容招募动物 | 动物成为可指挥队员 | 移动、战斗、喂养；不能默认获得所有人形交互 |
| H28 | 动物随游戏时间成长 | 年龄阶段与体格、能力变化 | 继续培养；年龄变化与普通技能经验分开 |
| H29 | 合适驮兽装备专用背包 | 承担运输、装卸和食物补给 | 受专用背包、体积、负重与供食规则限制 |
| H30 | 对倒地动物/特殊角色取出死亡关联物品，或尸体被处理 | 可取得肉、皮或特殊战利品；取走特定死亡物品可令倒地生物死亡 | 运输、烹饪、出售或处理；不是任意搜身都会杀死目标 |

**Unknown**：全部战斗开关组合、混合种族医疗优先级、失去手臂后的装备切换细节、濒死与装死间的全部转移。
动物繁殖、骑乘、魔法和通用复活不作为此清单的已确认原版能力；[动物资料](animals.md#breeding-and-eggs)的负面证据不能升级成对所有模组的断言。
