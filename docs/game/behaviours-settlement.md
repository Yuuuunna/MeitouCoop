# 工作与据点

[总索引与证据口径](behaviour-map.md)。默认 **Observed**；产品/建筑的不同数据实例不各自算一套系统。

## 工作调度

依据：[常驻工作](ai-tasks.md#perma-jobs)、[小队 AI](ai-tasks.md#squad-ai-options)、[搬运](buildings-production.md#hauling)。

| ID | 操作或条件 | 发生什么 | 后续操作与阻塞 |
|---|---|---|---|
| B01 | 对设施下一次工作命令 | 单位接近并进行对应动作 | 完成、失去条件或被改令后退出；不自动等于永久任务 |
| B02 | Shift 下支持常驻的工作命令 | 任务加入人物工作列表，可能带配套工作 | 持续重复执行；并非每种命令都能直接转换为常驻工作 |
| B03 | 调整、删除工作及切 Jobs | 改变任务顺序或自动工作的启用状态 | 当前能做的工作获得执行机会；医疗等例外需分别检查 |
| B04 | 工作需要原料、工具或空闲工位 | 寻找可用输入并移动到工位 | 没料、被占用、不可达或能力不足时等待/转其他工作 |
| B05 | 产品产出、背包或机器输出装满 | 依存储和任务规则搬运、入库或停工 | 腾空间、建设仓库、补运输者后恢复 |
| B06 | 手动命令、战斗、伤势中断工作 | 临时行为接管或阻止执行 | 解除后工作可能恢复；停止不是删除工作列表 |
| B07 | 设置医护、救援、保镖、炮塔、尸体处理等工作 | 自动寻找或持续服务合适目标 | 目标消失或资格变化后重新选择；各类寻找条件不相同 |

## 建造与资源

依据：[建造](buildings-production.md#construction)、[放置](buildings-production.md#placement)、[升级](buildings-production.md#upgrades)、[房屋购买](buildings-production.md#house-sales)。

| ID | 操作或条件 | 发生什么 | 后续操作与阻塞 |
|---|---|---|---|
| B08 | 打开建造菜单，选择已解锁项目 | 显示预览，移动、旋转及适用的高度/倾斜调整 | 合法位置可排放；地形、碰撞、室内外、权限影响放置 |
| B09 | 确认建设方案并派工供料 | 形成建造点，材料投入并推进施工 | 完工启用；缺料可补，未确认布局可撤销 |
| B10 | Prospect 勘探地点 | 查看水、肥力、矿产等资源条件 | 决定井、矿机、农田和据点位置；不产生资源物品 |
| B11 | 购买城镇内可售房屋 | 扣款并改变房屋所有权 | 修废屋、布置室内、使用建筑；不等于占领整个城镇 |
| B12 | 修复、升级或拆除自有建筑 | 状态、功能、资源与占地发生变化 | 再投入使用或重建；库存、占用者及材料返还需保持一致 |
| B13 | 操作可采铁、铜等矿点 | 劳动产生对应原矿 | 取走、入库、卖出或送加工；人数及输出容量限制效率 |
| B14 | 建造并操作采石与石材加工设施 | 取得石料，进一步制成建筑材料 | 供建设或储存；采掘与加工是不同步骤 |
| B15 | 冶炼铁、钢等加工链 | 消耗指定原料并产生中间材料 | 下一工序、出售或建设；需满足对应工艺与电力 |
| B16 | 井和取水设施满足资源条件 | 产生可运输的水 | 入库、浇田或供工艺使用；不由此推导角色口渴系统 |
| B17 | 化工、燃料和其他材料设备 | 配方输入转成指定产品 | 储运或供其他工序；不同配方由内容数据定义 |
| B18 | 合适熔炉接收可处理物品 | 物品被消耗并产生对应回收结果 | 取回产物、继续投料；具体可接受种类由设备规则限制 |

## 研究、制造与供养

依据：[研究](buildings-production.md#research)、[制造](buildings-production.md#crafting)、[农田](buildings-production.md#farming)、[电力](buildings-production.md#power)。

| ID | 操作或条件 | 发生什么 | 后续操作与阻塞 |
|---|---|---|---|
| B19 | 建立适当等级研究台，具备前置和研究材料 | 可把研究加入队列 | 缺等级、前置或成本则不能按正常条件开始 |
| B20 | 研究者工作，研究到达完成条件 | 知识/科技等级、建筑或生产能力解锁 | 建造新设施、选择后续研究；研究不是单纯购买物品 |
| B21 | 已知配方及合适制造台 | 添加、调整、删除制造任务或设置重复 | 操作者按可用输入制造；无工人/缺料/停电可阻塞 |
| B22 | 制造武器、护甲、弩、义肢等装备 | 消耗材料，产出相应品质和属性的装备 | 取货、装备、储存或出售；品质与技能、环境等有关 |
| B23 | 食物、酒类、织物等加工队列 | 原料按配方转为产品 | 烹饪供食、交易或下游加工；每种产品不另建专属命令系统 |
| B24 | 放置适合环境的农田或解锁的水培设施 | 建立作物生产点 | 投入启动材料、水及相应条件；普通农田与水培条件不同 |
| B25 | 作物生长，有水与环境条件 | 随时间成长，缺水/环境不适可影响产量或枯死 | 补水、等待成熟；不是有人站旁边才推进全部生长 |
| B26 | 成熟后派工收获与清理 | 收获物进入输出，收成受规则影响 | 搬出、再种植或处理枯死作物；逾期收获有损失风险 |
| B27 | 食物储存、队员携带与动物食槽 | 为合格角色提供可用食物来源 | 自动进食见 H18–H20；来源、距离和 AI 选项仍需满足 |
| B28 | 风力/燃料发电机启用 | 按风、燃料、损坏及开关等条件供电 | 加燃料、维修、建设更多供电或关掉负载 |
| B29 | 电池有余电或网络缺电 | 充电或补充供电 | 电池耗尽、主电恢复后状态变化；容量不是无限 |
| B30 | 切设备电源、是否使用电池 | 改变机器运行及电池使用许可 | 观察停机/效率原因；电力与材料/工位分别检查 |

## 据点使用

依据：[建筑 UI](ui-screens.md#selected-building)、[商店](economy.md#shops-and-transactions)、[门](locks.md#doors)、[势力事件](factions-squads-towns.md#campaigns)。

| ID | 操作或条件 | 发生什么 | 后续操作与阻塞 |
|---|---|---|---|
| B31 | 自有销售柜、可售货物及合格顾客 | NPC 购物使库存与资金变化 | 补货并允许访问；不是只放柜台就保证有营业额 |
| B32 | 建墙、门、坡道和炮塔 | 改变通路、封闭区域及防守位置 | 开关门、锁门、操炮、修门、抵御袭击 |
| B33 | 放置床、椅、灯、储物与训练设施 | 提供休息、照明、储运和训练用途 | 占用、照明、电力及室内空间影响使用；装饰未必有工作能力 |
| B34 | 调整建筑公共/私人访问、据点名称等 | 改变访问属性或地图/面板显示 | 来访、入侵与执法按相应规则响应；逐类型权限仍待核对 |

**Unknown**：工作全局仲裁及所有恢复边界、多人争工位、拆除有库存/占用建筑的完整结果、各生产队列取消和重复行为的实机细节。
据点袭击、税收、贸易来访与援军统一见 W17–W22，不在这里另建一份事件规则。
