# 人物与世界

[总索引与证据口径](behaviour-map.md)。默认 **Observed**；玩家不下命令也会发生的过程同样需要还原。

## 对话及人物服务

依据：[对话](dialogue.md)、[招募](dialogue.md#recruiting)、[动物购买](animals.md#buying-animals)、[合同](ui-screens.md#faction-tab)。

| ID | 触发或玩家选择 | 发生什么 | 后续可做什么及边界 |
|---|---|---|---|
| W01 | 对可交谈者下 Talk To | 接近并呈现该情境下的台词与回答 | 选择分支、结束、被打断；不是所有人物始终可交谈 |
| W02 | 选择回答，满足条件 | 根据人物、种族、关系、金钱、携带物、历史等筛选分支 | 继续回答或执行效果；同一个选项不保证在不同状态下可见 |
| W03 | 对话授予/收取钱物或改变关系 | 玩家状态随该内容变化 | 进入贸易、招募、合同、敌对等下一状态；文本和效果需一致 |
| W04 | 招募对话完成，条件及人数容量满足 | 角色加入玩家、可能进入外观/命名流程 | 编队、装备、下命令；拒绝、缺钱或满员应保留原关系 |
| W05 | 找到提供整容服务的角色 | 对话付费后打开允许的外观编辑 | 确认外观或退出；不是任意更换种族与身体历史 |
| W06 | 选择雇佣护卫或据点守卫 | NPC 接受限时保护合同 | 跟随或守基地，查看期限；续约依内容，不假定合同面板有通用续约按钮 |
| W07 | 动物商人出售动物 | 选择动物、确认价格与容量后加入玩家 | 命名、编队、饲养；买动物不等于拿走商人全部货物 |
| W08 | 赎买、救出或释放人物 | 对话及 AI 根据其条件选择反应 | 可能逃走、跟随或招募，见 P30 |
| W09 | 战败后被奴隶贩子、食人族等带走 | 关押、运输、奴役或伤害流程开始 | 另一队员营救，或该角色尝试逃脱；不同群体不共用同一种结局 |
| W10 | 队友、NPC 相遇、到达地点、战斗等事件 | 自动交谈、喊话、警告或环境对白 | 阅读记录、回应可中断对话；内容有条件、冷却及记忆 |

## NPC 与社会反应

依据：[AI](ai.md)、[感知](perception.md)、[经济与执法](economy.md)、[势力关系](factions-squads-towns.md#relations-and-world-states)。

| ID | 触发或玩家选择 | 发生什么 | 后续可做什么及边界 |
|---|---|---|---|
| W11 | 居民、商人、守卫和游荡队伍正常活动 | 按角色行为包工作、休息、巡逻、贸易或旅行 | 玩家可跟随、相遇、交互；不是所有 NPC 都具有所有生活行为 |
| W12 | 动物发现猎物、食物或危险 | 追逐、攻击、进食、逃跑等种类相关反应 | 绕行、猎取、救援；掠食者与家畜行为不同 |
| W13 | NPC 受伤、战斗结束或发现遗体 | 合适 NPC 治疗、抢掠、搬运、逮捕或处置目标 | 玩家介入、夺回装备、救人；不把全部 NPC 处理成只会攻击 |
| W14 | 他人看见、听到或识别玩家行为 | 警戒、目标记忆、追踪与敌我判断变化 | 躲避、伪装、逃跑或交谈；失去可见性不必立即清空记忆 |
| W15 | 攻击、帮助、交付赏金或剧情选择 | 个体/小队记忆及派系关系可能变化 | 盟友援助、敌对或拒绝服务；不是任何帮助都必然加关系 |
| W16 | 查看势力页或修改自己势力名称 | 查看已接触关系、有效合同和事件；更改名称 | 选择外交/行动方向；数值显示不等于玩家可直接编辑外交状态 |

## 事件与世界变化

依据：[战役与来访](factions-squads-towns.md#campaigns)、[城镇替换](factions-squads-towns.md#town-overrides)、[重要角色](factions-squads-towns.md#unique-characters)、[天气](../formats/weather.md)、[地图](ui-screens.md#map)。

| ID | 触发或玩家选择 | 发生什么 | 后续可做什么及边界 |
|---|---|---|---|
| W17 | 建据点并符合地域、人口、关系等条件 | 派系来访/袭击进入排程与行军 | 看到预告、准备防御、离开或接待；不是每个基地触发所有事件 |
| W18 | 税收、贡品、祈祷等队伍到达 | 发出对应对话要求 | 支付、配合、拒绝或不回应，触发相应内容后续 |
| W19 | 敌对袭击、掠夺或报复队伍到达 | 进入交战、突破、抢掠等任务 | 防守、谈判（若有）、逃离；胜负后撤退及后续由事件定义 |
| W20 | 商队或其他友好访问 | 进入据点并按访问内容活动 | 交易或交谈；访问不是每次都生成敌对战斗 |
| W21 | 符合盟友援助条件或已有守卫合同 | 援军/守卫加入防御活动 | 协同作战，任务完成或到期离开 |
| W22 | 事件胜败、拒付、击杀重要目标等 | 解锁、安排、重复或终止后续事件 | 下一次来访、报复或安全期；保持跨存读档一致 |
| W23 | 重要角色死亡、囚禁或派系条件改变 | 世界状态条件发生变化 | 影响后续人物、对话、队伍和城镇内容；不等于立刻切换整张地图 |
| W24 | 满足替换条件的城镇重新进入相应加载流程 | 城镇所属、居民和建筑内容可能替换 | 返回查看、贸易或战斗；不等于玩家可用通用按钮占领城镇 |
| W25 | 昼夜、酸雨、毒气、沙暴、危险水域等环境 | 可见/可听环境变化，并按地点和防护影响人物或生产 | 换防护、寻找掩蔽、改路线；具体危险及免疫见天气/种族资料 |
| W26 | 探索废墟、巢穴和遗址 | 发现地点、守卫、容器、资源和知识物品 | 潜入、战斗、开锁、带走成果，接回 P09/P10/B19 |
| W27 | 离开区域或切换远方队伍 | 近处与远处的更新方式不同，持久人物和事件仍需保持一致 | 返回或读档继续；不假定屏外每场战斗都逐帧模拟 |
| W28 | 所有可控角色失去行动能力或死亡 | 可继续的路径由是否仍有人活着、可恢复或获救决定 | 等待、救援、读档或新开局；无预设主线通关条件 |

**Unknown**：每条原版对话、事件、城镇替换的内容实例覆盖率，天气危害的全种族组合，屏外持续范围，以及全灭时的具体 UI 表现。
原版内容未证明的“派系自动全面征服地图”“任意占城”“通用任务日志系统”不因沙盒宣传而加入已确认能力。
