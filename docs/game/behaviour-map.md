# Kenshi 玩家能力与行为链

范围：原版 Kenshi 的玩家可见行为，以仓库已有的 1.0.68 资料为基线。
用途：先确定要还原的能力和结果，再讨论 Meitou 的实现边界与代码清理。
每行描述一种能力；人物、城镇、配方、对话和装备的不同内容通常是该能力的数据实例。

## 记录口径

- **Observed**：已有文档或公开资料支持的行为整理；每节链接依据。本清单未逐项完成原版实机复核。
- **Unknown**：证据不足的条件、组合或细节；不能据此要求 Meitou 实现猜测。
- **Verified**：须附原版版本、场景、实际操作和检查结果；不因旧文档或现有代码声称支持就升级。
- 表中的“可”表示条件满足时存在该分支；不表示始终显示、必定成功或各分支等概率。
- 本目录只维护玩家行为；公式、文件格式、内部机制仍由链接的主题文档维护。
  旧文档中的 Meitou 特有行为、推测和扩展不自动成为原版要求。

每项的完整契约是：**谁 → 对什么 → 什么条件下 → 做什么 → 立即反馈 → 状态变化 → 后续选择**。
“打开了面板”“已有某个系统类”都不足以证明一条链完成。
菜单可见、条目可选、接令、到达、执行、结算和反馈分别检查；例如可打开搜身窗口，
并不证明每件装备都能合法取走。按钮、快捷键、右键和自动工作若触发同一能力，应收敛到同一结果契约。

## 必须覆盖的状态维度

| 维度 | 需要区分的情况 |
|---|---|
| 操作者 | 无选择、单选、多选；人形、动物；清醒、昏迷、被背、被囚禁；双手及负重限制 |
| 目标 | 自己、队友、中立、盟友、敌人；站立、睡眠、倒地、死亡、被背、被关押 |
| 权限 | 自有、他人所有、公共、无人所有；公开区域、私人房屋；合法行为、犯罪 |
| 输入 | 短按、按住、拖动、松开；Shift；世界目标、头像、地图、面板；UI 是否占用输入 |
| 可达与资源 | 距离、楼层、门锁、寻路；钱、背包格、材料、工具、弹药、床位、工位、电力 |
| 并发 | 多人抢同一目标；目标移动、醒来、死亡或被别人带走；更高优先级工作和战斗介入 |
| 生命周期 | 取消、失败、重试、完成、恢复；暂停、加速、切换远方队伍、卸载区域、存读档 |

这些维度是待检查的边界，不是宣称原版在每种组合下都有相同规则。
按会改变结果的维度拆分场景，不穷举无关组合。

## 对照 Meitou 时的判据

每条链分别记录原版证据与 Meitou 结果：未核对、符合、部分符合、缺失、不适用。
实现存在与原版行为正确是两个问题；当前清单不沿用 roadmap 的模块勾选作为完成判定。
同一入口还需检查失败反馈、重复执行、被打断和恢复后的结果。

代码清理讨论以行为行号为依据：找出重复实现同一规则、UI 自行修改状态、无消费者的功能、
以及 Meitou 扩展与原版能力的边界。此处不规定类结构、代码行数上限或重写方案。
运行时玩法、资产与存档兼容、渲染音频、平台适配、工具和测试应分别衡量体量。

**Unknown**：所有菜单组合的逐项实机结果、各能力的 Meitou 符合度、完整模组兼容范围。
当前是覆盖各功能领域的行为清单，不是“所有分支已验证”的证明。
