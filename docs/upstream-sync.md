  创建、招募、移动成员和建队采用一致限制。独立小队与各玩家派系继续分别处理。
- 模组新角色／物品／工作／装备等观察器、保存字段、世界启动上下文、队伍选项、暂停命令和投射物回调接入无界面权威世界。
  检查点候选与活动世界隔离，缺失模组的选项和人口保留清理；投射物回调直接读取已结算的权威投射物源。
- 模组效果缩放／脉动、Tint／穿墙发光、武器尾迹及逐模组音频调制通过可靠增量同步。静态定义和动态值分别修订，
  客户端本地跟随骨骼、采样尾迹，不发送逐帧粒子或轨迹。撤销、过期、停止、视图切换和模组卸载保留生命周期处理。

  无法直接改写权威世界或其时钟。音频路径在两个图形 host 共用；上游 Metal 尚无对应效果／发光／尾迹渲染入口。

  避免每次标签变更重发完整成员表。旧基线不能恢复已撤销定义，命令仅回传摘要并继续校验当前物品及库存版本。
- 服务端仅重发尚未进入可靠通道的展示事件；客户端在激活前及 bulk 覆盖前保留事件，声音消费完毕才推进确认。
  去除额外的 128 声音静默丢弃路径，保留现有有界可靠 journal 和明确的溢出处理。
- `Engineering`、`Attacking`、自有角色医疗包状态、小队模板、研究时间、工作场所名称／类型等接入增量视图与客户端 UI。

- 上游 AI、医疗、建造、生产、交易、保存、导航、图形、音频、编辑器、启动器、报告服务、基准页面和本地化更新纳入。
