  交替捕获的快照不可变性、空列表关闭、未公开／重复／超限／null 提示拒绝，以及授权撤销和连接清理。
  关闭后库存内容及其版本消失，尺寸、允许披露的空状态和独立控制信息仍准确；暂停操作不推进世界 tick。
- 共享视觉使用生产 publisher／replica 校验精确浮点位与稳定身份；70,000 个累计短效 ID 和

  交错或晚到的旧基线不会复活已经撤销的效果；新清单完成前保留完整旧清单。
  另四项 publisher／replica 跨通道检查覆盖定义／读数乱序，以及成员集合和动态值的 A→B→A 变化；
  均在晚到的旧数据应用后立即核对可见结果，不依赖后续 bulk 修复。
- 粒子检查点诊断验证新版状态往返及旧版本缺省字段兼容。它验证保存格式与恢复逻辑，真实天气、资源和渲染仍需本地验收。

**Observed**（仓库外生产 API 带宽诊断）：500 个战斗角色、64 个固定锚点持续效果、256 个固定目标发光，
另加每秒 100 次炮台声音时，视觉参数以 4 Hz 改变的应用流量为 423.65 KiB/s，以 10 Hz 改变为 458.12 KiB/s。
每条应用消息另计 96 字节预算后，分别为 463.29 与 498.88 KiB/s；10 Hz 混合场景的余量很小。
这些是首次基线之后十秒的双向应用流量与预算模型，包含反向 ACK，初始基线另计；96 字节预留不是
QUIC／TLS／UDP／IP 开销实测，不能作为真实链路保证。完整负载、初始化流量和计量范围见
[带宽测量](networking.md#incremental-component-bandwidth)。

直接构造 DTO、刻意保持同一 ID 并以 10 Hz 改变锚点的高熵场景，与实际 `KeepEffect` API 负载分开计量；
加入相同声音负载后仍为 525.38 KiB/s（含上述预算），超过目标。
500 KiB/s/玩家是平均优化目标，不是新增硬限速，也不是任意模组和极端负载下的流量上界。
编码保持原有频率、精度与可靠交付语义。
